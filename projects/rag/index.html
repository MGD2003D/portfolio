    Adaptive RAG System

    Интеллектуальная система поиска и генерации ответов на основе неструктурированной информации

    Тезис УДК 004.8

    Github

    Общая информация

    Пользователь задает вопрос в боте, система находит ответ в корпоративной базе документов и отвечает строго на основе найденных фрагментов

    Система внедрена в агентство Trip For Students и Администрацию Невского района СПб

    Стек

    Слой Технология
    API FastAPI + Uvicorn
    Бот Aiogram
    LLM Qwen3-30B-A3B via Caila API
    Векторная БД Qdrant
    Эмбеддинги BAAI/bge-m3 + BM25 sparse
    Хранилище файлов MinIO
    Инфраструктура Docker Compose

    Система построена на FastAPI. Qdrant выбран как векторная БД с поддержкой именованных векторов — это позволяет хранить dense и sparse представления одного документа и искать по обоим одновременно. BAAI/bge-m3 даёт оба типа эмбеддингов из одной модели. MinIO используется как S3-совместимое хранилище документов с поддержкой событий — система реагирует на загрузку и удаление файлов.

    Как работает и ключевые решения

    Адаптивный выбор стратегии

    LLM классифицирует каждое сообщение: запрос информации, уточнение к предыдущему ответу или small talk. От классификации зависит стратегия — многоаспектный запрос запускает параллельный поиск по аспектам с weighted RRF fusion, уточнение учитывает историю диалога при генерации ответа, а small talk обрабатывается без обращения к базе. Оригинальный запрос всегда участвует в поиске с увеличенным весом, что гарантирует результат не хуже baseline.

    Гибридный поиск

    Qdrant хранит два вектора на каждый чанк — dense (для семантического поиска) и sparse (для точного совпадения), а результаты объединяются посредством RRF.

    Referral Fallback

    Когда ни один чанк не проходит порог релевантности, система не отвечает "не знаю". Вместо этого берёт топ-3 низкорелевантных чанка и просит LLM извлечь из них адреса, телефоны и организации — то есть куда обратиться напрямую.

    Rollback при ошибке индексации

    Если Qdrant падает в процессе индексации документа, файл автоматически удаляется из MinIO, что защищает от ситуации "файл есть в хранилище, но не проиндексирован".

    Консистентность данных

    Система при старте сравнивает файлы в MinIO с тем что есть в Qdrant, и переиндексирует недостающее. Документы, загруженные или удаленные через консоль MinIO, индексируются автоматически и удаляются через Event Listener.

    Результаты

    Hybrid search (dense + sparse, RRF fusion) — nDCG@10 0.83 на MS MARCO. Адаптивный выбор стратегии улучшает качество поиска на +4% nDCG@10 на запросах естественного языка (nfcorpus), при этом не ухудшая результат на экспертных доменах за счёт приоритета оригинального запроса.
